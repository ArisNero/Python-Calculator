# Python Calculator
This project resembles a calculator 
The purpose of this project is to learn the basics of Python

## Features
This calculator can show the user the sum(+), substraction(-), multiplication(*), divison(/) and modulo(%) of two real numbers;
The calculator will continue on unti the user presses "N" when asked if he/she would like to continue.

## Requirments

A working PC or Laptop. A code editor or IDE (Eg. Visual Studio Code). Python installed . The official Python extension(VS Code).

## How to get it running

Clone the repo. Press F5. Choose "Python Debugger". Choose "Python File".
